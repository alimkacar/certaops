## [0.1.0] - 2026-08-01

### Added

- Initial public release under the CertaOps name.
- Five domain-isolated agents for SAP platform operations, master data, planning, procurement,
  and project finance/reporting.
- Twenty-five bounded SAP tools, including controlled purchase-requisition writes and read-only
  procure-to-pay visibility.
- Deterministic RBAC/ABAC policy, runtime impact scoring, human approval, separation of duties,
  idempotency, reconciliation, evidence, and tamper-evident audit controls.
- D0–D3 data classification, field-level access policy, model-before-output DLP, masking,
  pseudonymization, retention, and tenant-isolated caching.
- Rich CLI, FastAPI service, Python API, S/4HANA simulator, OData V2/V4 adapters, and BTP
  Destination support.
- Unit, contract, policy, privacy, security, concurrency, performance, end-to-end, and optional
  live-SAP integration test suites.
